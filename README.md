# Stochastic Modelling of Traffic Accident Risk Using Markov Chains

## Overview
This project investigates traffic accident risk using discrete-time Markov chains.

## Methods
- Transition probability estimation
- State persistence analysis
- Joint Markov chain modelling with weather conditions

## Tools

- Markov Chains
- Stochastic Processes
- Statistical Modelling
